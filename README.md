# Credit Card Fraud Detection System (Work in Progress)

## Project Overview
This project aims to build a robust Machine Learning pipeline to identify fraudulent credit card transactions. Financial fraud costs the global economy billions, and this solution focuses on high precision and recall to minimize losses for financial institutions like Mastercard.

###  Key Objectives
**Class Imbalance Handling:** Implementing SMOTE (Synthetic Minority Over-sampling Technique) to handle highly imbalanced datasets.
**Predictive Modeling:** Comparing Random Forest, XGBoost, and Logistic Regression.
**Explainable AI (XAI):* Using **SHAP** values to explain the model's decision-making process.
**Real-time Deployment:** Building a Streamlit web app for instant fraud detection.

###  Tech Stack (Current & Planned)
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, SHAP, Matplotlib, Seaborn
- **Deployment:** Streamlit / Flask
